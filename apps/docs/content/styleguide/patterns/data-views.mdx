# Data views

The same Northwind Ops purchase orders, shown every way an internal tool needs
to show records. The table follows the structure of `CollectionList` from
`@buildpad/ui-collections`; everything else is stock Mantine composed with the
shipped theme, and all of it is interactive.

<Showcase>

## Data table

Search, a quick status filter, a collapsible filter panel and a column menu up top; select rows to get the bulk bar; the footer carries the count, page size and pagination. Try filtering until nothing matches.

<DataTableBlock />

The toolbar overlays, pinned open so you can see them without clicking.
