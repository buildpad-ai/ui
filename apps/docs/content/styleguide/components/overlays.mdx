# Overlays

Everything that floats above the page. Dropdown surfaces — popover, menu,
combobox, hover card — share one look (`--ds-radius-lg`, `--ds-shadow-lg`,
hairline border); modals and drawers add an overlay. Previews are pinned open so
you can read them without clicking, and every trigger opens the real thing.
