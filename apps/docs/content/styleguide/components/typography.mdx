# Typography

Headings are set in **Inter Tight** with tight tracking, everything else in
**Inter** at a 14px body size, code in **JetBrains Mono**. Text is ink by
default, `dimmed` for secondary information, and coloured only at the AA-safe
700 stop. See [Foundations](/styleguide/foundations) for the raw type tokens.
