# Layout

The primitives that place everything else. Layout components have no look of
their own, so the demos draw them as dashed ember guide boxes
(`--ds-primary-50` fill, `--ds-primary-200` outline). Spacing props take the
theme scale — `xs` 8px, `sm` 12px, `md` 16px, `lg` 24px, `xl` 32px — from the
`--ds-spacing-*` tokens.
