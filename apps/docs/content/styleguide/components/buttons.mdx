# Buttons & actions

Every way a Buildpad screen asks the user to act. A `Button` with no `color` is
the **ink CTA** — the one primary action per view — while `color="primary"` is
the ember brand CTA, reserved for brand moments. Everything else steps down
through `default`, `light`, `subtle` and `transparent`.
