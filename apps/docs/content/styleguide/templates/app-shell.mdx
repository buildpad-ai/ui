# App shell

The frame around every signed-in screen: a sidebar with the brand tile
and grouped navigation, and a blurred glass header with the account menu at
its top right. Your own
pages render in the main area. Here it holds the home page that `buildpad init`
generates.

<Callout type="info">
**What generates this**

- `buildpad init` installs the `design-system` module. It writes
  `components/layout/AuthenticatedShell.tsx` from
  `packages/cli/templates/components/layout/AuthenticatedShell.tsx`, the
  sidebar entries in `components/layout/navigation.ts`, and the `.bp-*` shell
  styles in `app/globals.css`. It also writes the home page,
  `app/[lang]/(authenticated)/page.tsx`, from
  `packages/cli/templates/app/authenticated-page.tsx`.
- `buildpad add api-routes` adds `app/[lang]/(authenticated)/layout.tsx`. That
  layout wraps every page in the route group with the shell. Route modules
  such as `buildpad add users-routes` add their own sidebar entries.
</Callout>

## Header anatomy

The breadcrumb on the left and the actions on the right, ending with the account menu. Search, notifications and the language switcher can each be turned off with a prop on `AuthenticatedShell`. In a workspace with several locales the shell adds a `LanguageSwitcher`, and a `ScopeSwitcher` passed through `headerActions` lets a user in several scopes switch between them.
